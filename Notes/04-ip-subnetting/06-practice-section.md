*IP Subnetting · Section overview · Source: https://www.networkacademy.io/ccna/ip-subnetting/practice-section*

The IP Subnetting Practice Section is designed to help learners master subnetting techniques through hands-on examples and exercises. This section covers four main lessons that will enhance the learner's understanding of IP subnetting concepts:

1. [Finding the Subnet ID](https://www.networkacademy.io/ccna/ip-subnetting/finding-the-subnet-id): This lesson introduces the process of determining the subnet ID by following a step-by-step approach. It provides the foundation for understanding how IP addresses are segmented into network and host portions.
2. [Finding the Subnet ID (Shortcut)](https://www.networkacademy.io/ccna/ip-subnetting/finding-the-subnet-id-shortcut): To speed up the subnetting process, this lesson teaches a shortcut method for quickly identifying the subnet ID. This technique will enable learners to solve subnetting problems more efficiently.
3. [Predictability Approach (without binary math)](https://www.networkacademy.io/ccna/ip-subnetting/predictability-approach-no-binary-math): This lesson focuses on a unique method to perform subnetting without relying on binary math. It simplifies the process and makes it more accessible to learners with varying levels of technical expertise.
