*Wireless Fundamentals · Section overview · Source: https://www.networkacademy.io/ccna/wireless/wireless-standards*

In this section, we will explore key wireless concepts and standards that define how Wi-Fi networks operate. These lessons will provide a solid foundation for understanding the technologies behind modern wireless communication. By the end, you will gain deeper insights into Wi-Fi protocols, frame structures, and the mechanisms that keep wireless data transmission efficient and reliable.

Here’s what you’ll learn in this section:

## 1. Wireless Standards

This lesson covers the evolution of wireless technologies and the IEEE standards that define Wi-Fi. You’ll learn how different 802.11 amendments (such as 802.11a, b, g, n, ac, and ax) have improved speed, coverage, and reliability over time.

## 2. 802.11 Frame Format

In this lesson, we will dive into the structure of an 802.11 frame. You’ll understand the purpose of each frame field, including the Frame Control, Duration, Address fields, and Frame Body. This is essential for understanding how wireless data is transmitted and received.

## 3. 802.11 Frame Types

Learn about the different types of 802.11 frames used in Wi-Fi communication. We’ll cover the three main frame types—Management, Control, and Data—and explain their specific roles in wireless networks. You’ll also understand how these frames enable tasks like device association, disassociation, and data transmission.

## 4. 802.11 Frame Addressing

Wi-Fi devices use MAC addresses to manage communication. This lesson explores how frame addressing works in different network modes (infrastructure, ad hoc, etc.) and how up to four address fields are used to handle device-to-device, access point, and network communication.

## 5. Collision Avoidance (CSMA/CA)

Wireless networks face a unique challenge—avoiding collisions since multiple devices share the same frequency. This lesson explains how CSMA/CA (Carrier Sense Multiple Access with Collision Avoidance) helps reduce collisions and ensures smooth data transmission in Wi-Fi networks. You’ll also learn about techniques like RTS/CTS (Request to Send/Clear to Send).

## 6. IEEE Wi-Fi Standards

In this lesson, we’ll take a closer look at the specific IEEE standards that govern Wi-Fi technology. You’ll learn about each standard’s frequency bands, data rates, channel widths, and key improvements. This includes standards from the early 802.11b to the high-performance 802.11ax (Wi-Fi 6).

By completing this section, you will:

- Understand the purpose and evolution of wireless standards.
- Gain detailed knowledge of 802.11 frame formats, types, and addressing.
- Learn how Wi-Fi networks handle collisions and avoid interference.
- Be equipped to analyze and troubleshoot Wi-Fi communication issues.
